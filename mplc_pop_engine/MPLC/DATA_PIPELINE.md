### STAGE 4: Evidence Detection & Labeling

**Input:**
- Account list for specific vertical (from Stage 3)

**Process (Example: Corporate Yelp Pipeline):**
```python
for account in corporate_accounts:
    # 1. Find Yelp URL (Apify Business Scraper)
    yelp_url = find_yelp_url(account.name, account.address)
    cost += 0.0025

    # 2. Download facility photos (Apify Photos Scraper)
    photos = download_yelp_photos(yelp_url, category='all', caption_filter=True)
    cost += 0.002 * num_photos

    # 3. YOLO pre-filter (free, runs locally)
    tv_candidates = []
    for photo in photos:
        detections = yolo_detect(photo, classes=['tv', 'monitor'])
        if detections:
            tv_candidates.append(photo)

    # 4. VLM classification (Claude Sonnet 4.5)
    for photo in tv_candidates:
        classification = vlm_classify(photo)
        # Returns: PROSPECT / SUSPECT / REJECTED
        # With: space_type, tv_powered_on, confidence
        cost += 0.01  # ~$0.01 per VLM call

    # 5. Determine final tier
    if any(c['tier'] == 'PROSPECT' for c in classifications):
        tier = 'PROSPECT'
    elif any(c['tier'] == 'SUSPECT' for c in classifications):
        tier = 'SUSPECT'
    else:
        tier = 'REJECTED'

    # 6. Save evidence
    save_evidence(account, tier, photos, classifications)

    # 7. Record in enrichment ledger
    record_enrichment(account.id, 'yelp_pop_detection', tier, cost)
```

**Output:**
- `pop_results_corporate_YYYY-MM-DD.csv`
  - account_id
  - account_name
  - tier (PROSPECT / SUSPECT / REJECTED)
  - evidence_photo_path
  - evidence_url
  - confidence
  - cost
- Evidence photos saved to: `verticals/corporate/evidence_photos/`
- Enrichment recorded in `enrichment_ledger.db`

**Cost per account:** ~$0.022 (Corporate), ~$0.119 (Auto)

## 90-Day Deduplication Flow

**Critical: Prevents double-spend on enrichment**

```
New weekly export arrives
    ↓
Extract unique accounts (31,225)
    ↓
For each account:
    Check enrichment_ledger:
        Last enriched < 90 days ago?
            → SKIP (save $0.022)
        Last enriched > 90 days ago?
            → ENRICH (data may have changed)
        Never enriched?
            → ENRICH
    ↓
Only enrich filtered accounts
    ↓
Record results in ledger with:
    - account_id
    - enrichment_date
    - result (PROSPECT/SUSPECT/REJECTED)
    - cost
```

**Example Savings:**
- Week 1: Process 31,225 accounts = $687 cost
- Week 2: 20% overlap (6,245 accounts), 80% new (24,980 accounts)
  - Skip 6,245 accounts = $137 saved
  - Process 24,980 accounts = $550 cost
- Week 3: Continue pattern...

**Annual savings from dedup:** Significant if customer base is stable
